# Licenze delle dipendenze

I testi sono conservati integralmente. Il bundle raccoglie inoltre le licenze
dalle distribuzioni Python installate e dalle risorse Tcl/Tk locali.

- PyWinRT 3.2.1, incluse le proiezioni `winrt-*`: [licenza MIT originale](https://github.com/pywinrt/pywinrt/blob/v3.2.1/LICENSE).
- Tcl 8.6.16: [licenza originale](https://github.com/tcltk/tcl/blob/core-8-6-16/license.terms).
- Tk: `license.terms` fornito con il runtime Python utilizzato per la build.

La licenza MIT del progetto Sentinella si trova nel file `LICENSE` alla radice.
